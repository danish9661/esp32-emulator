Build, test, reproduce

Rebuild the engine

npm run build:wasm   # Rust → WASM
npm run build        # esbuild dist/ bundle
npm test             # no-server battery

Run the peripheral suite

node tests/compile-server.mjs  # :5525
node tests/test-worker-gpio.mjs
./tests/run-worker-tests.sh --skip-bt --skip-wifi
Reading the console verdict. Each demo ends with the chip’s own verdict line (RESULT=PASS or the peripheral mark such as CAM_DATA=PASS). The host never prints a pass mark — if the mark is missing, the demo genuinely did not finish.
